- Nama organisasi: **Pejabat Bendahari Agung Kehormat (PBAK)**
- Nama repository GitHub: `hiper-jppipgkkb`
- Nama projek Vercel: `hiper-jppipgkkb`
- Nama Google OAuth client: `HiPER Web`
- Tajuk pelayar: `HiPER | PBAK JPP IPGKKB`

## Peraturan penggunaan

1. Gunakan **HiPER** untuk nama website atau produk.
2. Gunakan **PBAK** apabila merujuk pejabat, pentadbir, peraturan atau pengumuman rasmi.
3. Jangan menukar nama jadual database hanya kerana penjenamaan.
4. Jangan menukar Supabase project reference atau URL sedia ada.
5. Jangan memasukkan rahsia OAuth atau `service_role` key ke dalam repository.
